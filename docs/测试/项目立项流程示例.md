# 项目立项流程示例

## 适用范围

本流程适用于公司内部新项目的立项，包括产品研发、市场活动和流程优化。进行中的项目追加预算超过原预算 20% 的，按新的立项材料重新评审，不在原单上口头追加。

## 立项前准备

- 项目目标可量化，例如上线日期、影响的部门或要替换的旧流程。
- 已经检索过在途项目，确认没有重复立项。
- 预算和人力有初步估算。估算可以是区间，但不能空白。

立项申请必须在项目启动前提交。先启动后补申请的，原则上不予受理。P0 故障的临时排障不属于立项，走故障流程。

## 申请步骤

1. 填写《项目立项申请表》，写明目标、范围、里程碑和明确不做的事项。
2. 提交直属负责人审批。
3. PMO 统一评审排期。评审会每两周一次，材料须在会前 2 个工作日提交，否则顺延到下一场。
4. 评审通过后才能召开项目启动会。未通过的项目不得占用跨部门人力。

## 需要提交的材料

| 材料 | 是否必需 | 说明 |
| --- | --- | --- |
| 立项申请表 | 是 | 含目标、范围、里程碑 |
| 预算明细 | 是 | 超过 5 万元需财务会签 |
| 资源需求清单 | 否 | 涉及跨部门时必填 |

预算 5 万元及以下由部门负责人审批。超过 5 万元的，财务会签后才能进入 PMO 排期。

## 常见问题

**问：立项被驳回后能否再次提交？**
可以。按驳回意见修订后重新提交，同一项目最多提交 3 次。第 3 次仍未通过的，本季度不再受理同一目标。

**问：市场活动只有一周准备期，能否先做再补立项？**
不能。可以申请加急，材料在评审会前 1 个工作日提交，由 PMO 决定是否插入本场。未批准前不对外发布活动。
