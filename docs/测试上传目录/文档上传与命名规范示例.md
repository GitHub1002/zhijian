# 文档上传与命名规范示例

## 适用范围

本规范适用于上传到知识库的 Markdown 文档。图片可以放在文档同目录，但问答只索引 Markdown 正文。

## 文件命名

- 使用中文或英文，避免特殊符号。
- 名称概括内容，例如 `报销流程.md`、`新员工入职手册.md`。
- 同一目录下名称不可重复。更新制度时改原文件，不要另存为“报销流程-新.md”和旧文件并存。

## 内容格式

1. 一级标题作为文档名。
2. 用二级、三级标题划分可以单独提问的规则。
3. 步骤使用有序列表，并列条件使用表格。
4. 金额、天数、时限写成数字。

## 目录

| 目录 | 用途 | 对应知识库 |
| --- | --- | --- |
| `hr` | 人事制度与流程 | HR |
| `it` | 网络、设备与账号 | 运维 |
| `运维` | 故障、发布、告警 | 运维 |
| `运营` | 客服与业务流程 | 运营 |
| `开发` | 接口与工程规范 | 开发 |
| `人工智能` | 问答规则与写作规范 | 人工智能 |

放错目录会进错知识库。人事制度放进 `运营` 后，只有运营库权限的人能检索到。

## 上传之后

保存文件后重建索引，问答才会使用新正文。示例结构：

```text
# 费用报销流程

## 适用范围
全体员工因公产生的费用报销。

## 报销类别
- 差旅费：一线城市住宿不超过 500 元/晚
```

示例中的数字必须和正式制度一致。
