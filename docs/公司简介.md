# 公司简介

## 关于我们

本公司成立于 2015 年，是一家专注于企业级软件解决方案的高科技企业。总部位于北京，在上海、深圳、成都设有分公司。

## 主营业务

- 企业数字化平台建设
- 数据分析与智能决策
- 云计算与信息安全服务

智检是公司内部使用的知识库，用来按已授权文档回答问题并标出来源。它不是对外销售的产品名称，对外介绍仍使用上述三项业务。

## 组织架构

公司下设产品研发部、市场营销部、客户服务部、人力资源部、财务部、行政部六个部门。信息技术与运行值班归产品研发部中的运维组，不单独设第七个部门。

| 部门 | 主要职责 | 常用知识库 |
| --- | --- | --- |
| 产品研发部 | 产品、研发、测试、运维值班 | 开发、运维、人工智能 |
| 市场营销部 | 对外介绍、活动立项 | 运营 |
| 客户服务部 | 发货时效、退换货、工单 | 运营 |
| 人力资源部 | 招聘、入职、请假、考勤 | HR |
| 财务部 | 报销复核、退款提交 | HR、运营 |
| 行政部 | 前台、门禁、办公用品采购 | HR |

## 办公地点

- 北京总部：工作日 9:30–18:30 接待入职和访客。
- 上海、深圳、成都分公司：当地行政前台办理入职领取设备，合同仍由总部 HR 归档。
- 不设海外办公室。远程办公通过 VPN 申请，不因所在城市自动开通。

## 企业文化

使命：用技术赋能企业发展。
愿景：成为行业领先的数字化服务商。
价值观：客户第一、团队合作、拥抱变化、诚信敬业。

价值观不代替制度。发货时效、报销标准和权限审批以对应制度中的数字为准。

## 常见问题

**问：公司有几个部门？**
六个：产品研发部、市场营销部、客户服务部、人力资源部、财务部、行政部。

**问：分公司员工第一天去哪里？**
到当地行政前台报到，时间为入职当日 9:30。设备由当地 IT 发放，知识库权限仍在智检中申请，由管理员审批。
