# 示例知识库文档

这里是可公开发布的示例文档，方便试用智检的检索、引用和权限。

> 真实的员工信息、密钥、生产配置和未公开合同不要放进公开仓库。示例里的金额和时限只供演示问答。

## 添加或更新文档

1. 把 Markdown 放进 `docs/` 对应目录。
2. 标题写出主题，规则写明数字、步骤和例外。
3. 重建索引。只保存文件不会更新已有回答。

```powershell
python -m scripts.ingest
```

也可以在页面里由管理员执行索引。

## 目录

- `docs/common/`：公司简介，登录后即可阅读，不必申请
- `docs/hr/`：入职、招聘、请假、报销、考勤、试用期
- `docs/it/`：设备、账号、网络安全
- `docs/运维/`：故障、发布回滚、告警与交接
- `docs/运营/`：发货时效、退换货、知识库维护
- `docs/开发/`：接口规范、可访问性、代码评审
- `docs/人工智能/`：检索与回答规则、引用模板、写作规范

招聘、游戏开发、股票和 AI 概念等长文档仍留在仓库里，但不进入正式索引。
