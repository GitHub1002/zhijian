# 办公设备与账号

## 新员工入职设备

新员工入职当日，IT 部门会发放：

- 笔记本电脑一台
- 显示器一台
- 门禁卡一张

员工须核对资产编号并在《资产领用单》签字。设备仅限本人办公使用，不得转借。离职时按资产编号归还，缺少电源或出现非正常损坏的，按残值从工资结算中处理。

## 软件安装

公司统一使用以下软件，可在内网软件中心自助安装：

- 企业微信
- 办公套件
- 开发工具（按岗位需要）

不在软件中心的工具，向 IT 提交申请，说明用途和期限。未经批准不得安装远程控制、未知来源加速器和个人云盘客户端。开发工具只安装岗位需要的编辑器、运行时和数据库客户端，不在办公电脑上运行生产数据库副本。

## 账号申请

### 邮箱

入职后系统自动开通企业邮箱，格式为 `姓名拼音@company.com`。重名时在拼音后加部门缩写，由 IT 确定，员工不能自行改地址。邮箱容量 50 GB，超过 90% 时清理或申请归档，不自动扩容。

### VPN

远程办公需申请 VPN 账号，向 IT 部门提交申请，审批后 1 个工作日内开通。VPN 只访问邮件、代码仓库、文档和经批准的内部系统，不默认开放生产服务器。账号 90 天未使用的自动冻结，重新启用须再次申请。

### 智检

知识库账号由员工自行注册，权限须另按《员工入职与权限申请》提交。注册成功不等于已经可以阅读全部文档。

## 设备报修

设备故障可通过 IT 服务台提交工单，响应时间：

- 紧急故障：2 小时内响应。紧急指无法开机、整组无法上网或门禁大面积失效。
- 一般故障：1 个工作日内响应。一般指单台电脑软件异常、显示器无信号、打印机卡纸。

报修时写明资产编号、现象和是否影响当日对外服务。可以继续使用的电脑不要自行重装系统。配件更换由 IT 登记，旧件交回，不丢弃。

## 常见问题

**问：显示器不够用可以再领一台吗？**
研发和设计岗位可以申请第二台显示器，其他岗位默认一台。申请须直属负责人确认，IT 有库存时 2 个工作日内发放。

**问：电脑带出办公室需要登记吗？**
需要。当日外出在行政前台登记带回时间；过夜或跨城携带须直属负责人审批。未登记携带出门禁的，门禁系统会告警给 IT。
