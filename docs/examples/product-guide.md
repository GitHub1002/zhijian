# 产品入门指南（示例）

## 产品定位

智检是本地知识库。它只根据当前用户已获批文档回答，并在结论后标出来源。文档里没有的内容会拒答，不会用常识补上。

## 快速开始

1. 安装依赖：`pip install -r requirements.txt`。
2. 复制 `.env.example` 为 `.env`，填写 DeepSeek 密钥。密钥不要提交到仓库。
3. 确认重排模型为 `BAAI/bge-reranker-v2-m3-int8`。
4. 把 Markdown 放入 `docs/` 对应目录。
5. 执行 `python -m scripts.ingest` 建立索引。
6. 启动服务后访问 `http://127.0.0.1:8688`。

## 权限

新注册账号没有任何库权限。提交申请并由管理员通过后，才能看到对应文档，问答也只在这些库里检索。管理员拥有全部库。

## 如何更新知识库

新增或修改 Markdown 后，由管理员在页面执行索引，或再次运行 `python -m scripts.ingest`。服务正在占用本地向量库时，不要另开一个进程同时索引。

## 常见问题

**问：为什么回答一下子全部出现？**
当前问答不是流式输出。生成完成后一次性显示，并附来源。

**问：每天可以问几次？**
默认每天 10 次。尚未获批任何库时的拒答不计入次数。
